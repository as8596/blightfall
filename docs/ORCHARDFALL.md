# Orchardfall — the valley outside the gate

Zone 1. The first place the player goes that is not Ambry, and the first place
in the game that can hurt them.

Generated by `tools/build_orchardfall.gd`. Everything below describes intent;
the tool is the source of truth for numbers.

---

## Six areas, not one field

A zone built as a single large rectangle is a room with a long walk in it. You
can see the whole thing from the middle, so there is nothing to find, no reason
to remember where anything was, and no way for the place to have a far end.

Six connected areas instead, and the graph is deliberately **not a tree**:

```
              [ AMBRY ]
                  │  south gate
          ┌───────┴────────┐
          │  valley road   │──── E ────┐
          └───────┬────────┘           │
                  │ S            ┌─────┴──────┐
          ┌───────┴────────┐     │  millpond  │
          │  orchard rows  │     └─────┬──────┘
          └───┬────────┬───┘           │ S
              │ S      └──── E ──┬─────┴──────┐
      ┌───────┴──────┐           │  terraces  │
      │  cider yard  │           └─────┬──────┘
      └───────┬──────┘                 │ S
              └────── E ──────┬────────┴──────┐
                              │   deep rows   │
                              └───────────────┘
```

Eight edges, every one two-way, and a circuit through the middle four —
valley road → orchard rows → terraces → millpond → valley road. Getting back is
never a matter of retracing your steps exactly, which is most of what makes a
place feel navigable rather than memorised.

| Area | Size | What it is |
|---|---|---|
| **The Valley Road** | 30×24 | Arrival. A road, a fork, a signpost. Read in three seconds. |
| **The Orchard Rows** | 34×28 | The namesake. Planted rows with aisles you can see down. |
| **The Millpond** | 26×26 | Water, a bridge, the mill on the far shore. |
| **The Terraces** | 30×30 | Stepped retaining walls with gaps. The climb. |
| **The Cider Yard** | 24×20 | A yard, barrels, and the zone's one interior. |
| **The Deep Rows** | 32×26 | The far end. Where the Warden's Hook will be (GDD §6). |

## Edges are walked into. Doors are pressed.

The two rules are opposites and both are deliberate.

A **door** (`world/doorway.gd`) is a threshold you choose. Brushing past one on
the way somewhere else must never blank the screen and move you, so the
keypress *is* the safety.

An **edge** (`world/gateway.gd`) is not a threshold, it is the end of the
ground. The path runs off the screen and the only thing you can do there is keep
going. Asking for a keypress to continue walking in the direction you are
already walking is a tax on the one input that needs none.

Both use the same fade, because arriving should feel the same wherever you came
from.

### The arrival bounce, and why every opening is four tiles deep

Each exit emits two markers:

- a **`Gateways`** marker on the outermost row of the opening — where the
  trigger sits
- an **`Edge_<facing>`** marker two rows inside it — where you land arriving
  from the other direction

An exit heading north targets the neighbour's `Edge_south`: you come in through
the edge that faces back the way you came.

If those two ever collapse onto each other the player fades into an area, lands
on the trigger they arrived through, and ricochets between two maps forever with
no input accepted. Two guards, because the failure is unrecoverable rather than
merely wrong:

1. The markers are two rows apart by construction.
2. `Gateway._armed` starts false and only arms once the player has been clear
   of the shape for one physics frame — so arriving *inside* a gateway still
   cannot fire it.

`tests/gateway_test.gd` checks the second one the only way that means anything:
by arriving and then standing still for a second.

## How the tool builds an area

Order matters, and it is the order that makes reachability structural rather
than lucky:

1. ground fill
2. patches
3. scatter and planted rows
4. **paths carved through all of it** — carving clears whatever the scatter put
   there, so a road cannot be blocked by a tree placed before the road was
5. features, bridges, the one building
6. the border ring, punched through at the exits

The scatter uses a fixed seed. Layout that moved between runs would make every
assertion below a coin toss.

### What the tool refuses to write

Run it and it checks, per area:

- every exit's trigger row is standable from the arrival point
- every POI is reachable
- the cider house's **doorstep** is reachable (doors are solid; the tile in
  front of one is what has to be walkable)
- the border holds everywhere it is not an opening — a gap in it lets the
  player walk into the trees, keep going, and end up outside the map with the
  camera unclamped

And across the zone, before a single tile is written:

- every exit has a matching exit coming back
- every area is reachable from the valley road

A one-way edge looks exactly like a two-way one until somebody walks through it
and cannot get back — by which point they are standing in an area with a full
satchel and no way home.

Two layout bugs were caught this way on the first build. The blight closed the
only route to the Warden's stone in the deep rows, and it was invisible in a
screenshot; and the millpond's bridge crossed to a shore with nothing on it,
which is scenery pretending to be a route.

## Two things about the blight

`blight_creep` is **solid**, so a ground patch of it is an invisible wall the
size of the patch. The deep rows were first built with two large patches and
half the area was impassable while looking completely fine.

It is also, per GDD §8, the one saturated colour in the game — which only works
while it is an accent. Half a screen of it is wallpaper.

So it is scattered as clumps you weave between, on dead ground, and it is never
laid down as terrain.

## Not built

- **No enemies.** Every area is `is_safe = false`, so nothing stops them being
  placed, but nothing is placed. Encounter design is its own pass.
- **No pickups.** Same story, and the same reason the satchel still has no
  source (`docs/WISHLIST.md`).
- **The Warden's Hook.** GDD §6 puts it here and it opens Stillwater. There is
  a shrine and a POI marking where.
- **The north road.** `docs/AMBRY.md` calls it the short way to Orchardfall. It
  is behind the wall, so it is mid-game, and the gate stays shut.
- **Nothing to fight over.** Which is the point of the next pass, not this one.
